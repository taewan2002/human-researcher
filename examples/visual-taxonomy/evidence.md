# Taxonomy 분류 근거

검토일: 2026-10-07. 자료 범위는 [가상 문헌 발췌 5개](../../tests/fixtures/visual-papers.md)와 [연구 메모](../../tests/fixtures/visual-project.md)입니다. 원문이나 실제 성능 표를 읽었다고 가정하지 않습니다. SVG는 연구 질문에 맞춰 편집한 잠정 분류입니다.

| ID / 버전 | 추론 입력 | 점수 산출 방식 | 남은 정보 |
|---|---|---|---|
| R1 / v1 | 텍스트만 | 학습 | 긴 입력 평가·수치 결과 |
| R2 / v2 | 텍스트 + 메타데이터 | 학습 | 평가 입력 길이·수치 결과 |
| R3 / v1 | 메타데이터만 | 고정 | R1·R2와의 직접 수치 비교 |
| R4 / v1 | 텍스트 + 메타데이터 | 혼합 | 두 분기의 기여·직접 비교 |
| R5 / v3 | 미확인 | 미확인 | 입력·학습·평가 세부 |
| B / 제안 | 텍스트 + 메타데이터 | 학습 | 실행 조건·평가 결과 |

트리의 첫 분기는 **최종 점수를 구성하는 방식**, 다음 분기는 **추론 시 사용하는 입력과 결합 방식**입니다. 학습과 고정 분기가 함께 있는 R4는 혼합으로 분류했습니다. 단순히 일부 학습 요소가 있다는 이유로 전부 학습 방식인 R2와 동일시하지 않습니다. 분류가 어려운 R5는 트리 밖에 둡니다. 위 표는 트리의 분류 근거를 비교하기 위한 보조 자료입니다.

## R1

위치: 문헌 발췌 `R1 — Compact Text Ranker, version 1` 절. 텍스트 기반 supervised ranking loss와 추론 시 메타데이터 미사용이 명시되어 있습니다. 짧은 문서 평가만 제시됩니다.

## R2

위치: 문헌 발췌 `R2 — Field-Aware Ranker, version 2` 절. 텍스트·게시 날짜·출처 유형을 학습 scoring layer에 결합합니다. 평가 길이는 발췌에 없습니다. R1을 인용하지만 지도는 인용 그래프가 아니므로 화살표로 표현하지 않았습니다.

## R3

위치: 문헌 발췌 `R3 — Metadata Rules, version 1` 절. 게시 날짜·출처 유형의 고정 규칙이며 텍스트와 학습 파라미터를 사용하지 않습니다. 짧고 긴 문서 평가를 포함하지만 수치 비교는 제공되지 않았습니다.

## R4

위치: 문헌 발췌 `R4 — Mixed Signals, version 1` 절. 학습한 텍스트 점수와 고정 메타데이터 점수를 추론 시 결합합니다. 두 분기의 기여를 분리한 결과는 없습니다. 따라서 두 입력을 사용하는 혼합 방식입니다.

## R5

위치: 문헌 발췌 `R5 — Ranker in Practice, version 3` 절. 초록만 접근 가능하며 production ranking system이라는 설명 외에 분류에 필요한 입력·학습 정보가 없습니다. 메타데이터를 쓰지 않는다고 결론 내릴 수 없습니다.

## B

위치: 연구 메모의 `Selected direction`과 `Proposed comparison`. 선택한 방향 B는 텍스트와 외부 메타데이터를 결합합니다. 같은 encoder와 scoring head의 메타데이터 사용·제거 조건을 학습해 비교할 계획입니다. 셔플 조건은 정보 연결의 의미를 확인하는 대조 조건입니다.

B는 R2와 같은 범주입니다. 가장 가까운 문헌과의 차이, 길이·가용성 조건에서의 효과는 추가 근거와 실험으로 확인해야 합니다. 지도에서 분류한 위치만으로 방법의 신규성이나 우월성을 주장하지 않습니다.
