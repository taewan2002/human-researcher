# RetoVLA 연구를 위한 proposal

[HTML로 읽기](proposal-reader.html) · [수정용 Markdown](proposal.md) · [선행연구와 작성 범위](sources.md) · [VLA taxonomy](taxonomy.svg) · [갤러리](../README.md)

**경량 VLA의 시각 정보를 작은 register 요약으로 모아 행동 생성에 전달하면, 계산 비용을 제한하면서 조작 성능을 높일 수 있을까요?** 이 질문으로 RetoVLA 연구를 제안합니다.

연구를 시작하는 시점의 관점에서 필요성·가설·방법·비교군·판단 기준·견적을 작성한 예제입니다. RetoVLA의 완료된 성능표나 채택 결과를 제안의 근거로 사용하지 않습니다. 실제 과거 proposal 원본은 아니며 작성 배경은 [출처 기록](sources.md)에 분리했습니다.

## 이 제안서에서 확인할 수 있는 것

1. VLA 대표 정책 8편과 제안 방법의 계층형 taxonomy, 총 13편의 선행연구를 연결하고, 가장 가까운 방법과의 차이에서 질문을 도출합니다.
2. 기준선·단순 pooling·register 요약이 각각 무엇을 확인하는지 보여줍니다.
3. 성공률·공간 관계·계산 비용을 나누어 측정합니다.
4. 이득·무효·손해·판단 부족에 따라 주장을 정합니다.
5. 기준선의 실패 양상으로 필요성을 점검하고, 조건부 일정과 계산 예산을 산식으로 보여줍니다. 수치는 계획 가정이며 실측 결과가 아닙니다.

문헌은 연구 시작 관점을 위해 2025-09-24 이전 공개 버전을 사용했습니다. 현재 최신 동향을 망라하는 survey가 아니며, 조회일과 접근 제한은 [출처 기록](sources.md)에 남겼습니다.

`proposal-reader.html`을 내려받거나 로컬 저장소에서 더블클릭해 브라우저로 열어 주세요. 서버·API 키·외부 폰트가 필요하지 않으며 원문 링크를 열 때만 인터넷을 사용합니다. 인쇄는 여러 페이지의 읽기 문서입니다.

## 내 아이디어로 요청하기

```text
write-proposal로 이 아이디어의 연구 제안서를 작성해 주세요.
핵심 질문은 [질문], 제안 방법은 [방법], 사용할 수 있는 자원은 [자원]입니다.
연구 필요성 → 선행연구와의 차이 → 가설 → 방법 → 비교 실험 →
결과별 판단 → 자원·일정을 연결해 주세요.
아직 실험 결과는 없습니다. 예상 효과를 관측 사실처럼 쓰지 말아 주세요.
직관적인 방법 도식이 있는 HTML과 수정용 Markdown으로 만들어 주세요.
인용에는 논문 제목·원문 링크·실제로 읽은 위치를 붙여 주세요.
```
