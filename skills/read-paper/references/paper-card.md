# Paper card and source identification

Use only fields needed for the reading question; a short summary needs no full card.

**Paper:** Recognizable title — author(s), year, version when known; link the title only to a URL present in the supplied material or actual tool output.
**Access:** Material actually inspected and its provenance, including synthetic source labels.
**Reading question:** …
**In plain language:** Problem, proposed change, and why it matters.

| Claim or question | What inspected evidence supports | Locator, conditions, and limitation |
|---|---|---|
| … | … | Actual section / figure / table / page |

**What this changes for my research:** …
**Next passage / unresolved point, if requested:** …

For an absent link, write **링크 미확인 — 제공 파일 P01.md** / **Link unverified — supplied file P01.md**. Keep unknown metadata empty or explicit. A supplied URL is not itself evidence that the link was checked or the full text read.

Use a deep link only if supplied or returned by a tool; otherwise place the locator beside the paper title. Distinguish printed page numbers from PDF indices, and abstract-only access from full-text evidence.
