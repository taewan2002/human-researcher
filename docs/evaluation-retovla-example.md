# RetoVLA proposal 예제 검증

확인일: 2026-10-09 · [예제](../examples/retovla/README.md) · [출처와 읽은 범위](../examples/retovla/sources.md)

## 이번 변경의 범위

공개된 RetoVLA 설계를 연구 시작 관점의 proposal로 재구성했습니다. 선행연구 13편, 대표 VLA 정책 8편과 제안 방법의 계층형 taxonomy, 가설·비교군·결과별 판단, RTX 5090 GPU 1개 기준의 조건부 견적을 제공합니다. HTML 본문의 개인 소개를 제거하고 제작자 소개는 프로젝트 README에 두었습니다.

이 예제는 사용자 피드백에 따라 작성·편집·검토한 결과물입니다. 한 번의 무개입 스킬 실행 결과나 스킬의 효과 측정치로 제시하지 않습니다. RetoVLA의 완료된 성능 결과로 제안 효과를 미리 결론 내리지 않았습니다.

## 확인한 항목

| 항목 | 결과 |
|---|---|
| 저장소 구조 | 연구 스킬 7개와 안내 스킬 1개, 행동 사례 정의 49개 검증 |
| 단위 테스트 | 64개 통과 |
| 화면 폭 | 1440·1024·768·390·320px에서 페이지 전체 가로 넘침 없음 |
| 출처와 이동 | 출처 카드 13개, 내부 링크·원문 근거로 이동·돌아오기·키보드 이동 확인 |
| Taxonomy | 노드 17개, 범주 소속 연결 16개, 문헌 링크 8개, 제안 방법 1개; 레이블이 상자를 벗어나지 않음 |
| 문서 일관성 | HTML·Markdown의 장비를 RTX 5090 GPU 1개로 맞추고 인원 가정 제거 |
| 읽기와 인쇄 | 텍스트 트리·학습 조건 펼치기, 인쇄 시 접힌 본문 표시 확인 |
| 독립 파일 | HTML과 SVG를 로컬 파일로 열어 확인; HTML 읽기에 외부 네트워크 요청·페이지 오류 없음 |

문헌 분류는 버전별 원문 방법 구역을 확인해 작성했습니다. 그림의 선은 인용이나 성능 순위가 아니라 범주 소속입니다. 조회 범위와 API 접근 제한은 출처 기록에 남겼습니다.

## 검증하지 않은 것

이번 변경은 예제와 소개 문서의 보강입니다. 스킬 지침·설치 코드·라우팅 description을 변경하지 않았으며, 새 모델 행동 평가를 실행하지 않았습니다. 실제 GPU 학습이나 로봇 평가를 수행하지 않았고, RTX 5090의 처리량·실행 시간·메모리 적합성을 실측하지 않았습니다. 기간과 GPU 시간은 proposal의 계획 가정입니다.
