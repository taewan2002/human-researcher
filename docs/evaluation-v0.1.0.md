## 실제 실행 조건

- Claude Code **2.1.294**, effort `low`, 실제 응답의 모델 ID는 **`claude-sonnet-5-5`**, **`claude-opus-5-5`**입니다.
- 행동 비교에는 새 임시 작업공간과 프로세스를 사용했습니다. `--safe-mode`로 호스트 사용자 지침·스킬·플러그인·훅·MCP를 끄고 세션을 저장하지 않았습니다. 해당 스킬 본문만 프롬프트에 넣고 패키지 참조 파일은 읽을 수 있게 했습니다.
- 실행 모델은 평가 기준을 보지 않습니다. 사용 가능한 도구는 Read·Glob·Grep·Write·Edit이며 셸·웹 도구는 열지 않았습니다. 작업공간 내 사용 제한은 프롬프트에도 명시했습니다. 렌더링·실험 실행 사례의 검증으로 해석하지 않습니다.
- 판정은 별도 Codex CLI의 **`gpt-6-astra`, low**가 요청·원자료·출력·실제 산출물과 기준을 보고 수행했습니다. 조건 이름과 스킬 본문은 판정에서 숨겼습니다. 다른 계열의 판정도 정답을 보장하지는 않습니다.
- 새 10개 사례와 기존 실패 관련 6개를 선택했습니다. 무효 결과, 동등성, 인과 추론, 지표와 개념, 이해도, 자원 의존성, 안내 경계를 포함합니다. 과도한 단정을 막는 사례와 충분히 한정된 결론을 허용해야 하는 사례를 함께 두었습니다.

## 비교와 수정 과정을 모두 기록합니다

숫자는 **모든 기준을 통과한 사례 수 / 실행한 사례 수**입니다. 화살표는 스킬 미사용 → 사용이며, 서로 다른 단계의 결과를 합쳐 단일 성공률로 만들지 않습니다.

| 단계 | Sonnet 5.5 | Opus 5.5 |
|---|---:|---:|
| 첫 비교: 16개, 스킬 유무 | 8/16 → 10/16 | 7/16 → 14/16 |
| 1차 수정 후: 사용 조건 12개 | 7/12 | 6/12 |
| 2차 수정 후: 16개, baseline 재사용 | 8/16 → 11/16 | 7/16 → 13/16 |
| 이해도 질문 템플릿: 사용 조건 1개 | 1/1 | 1/1 |
| 안내·예산 템플릿: 사용 조건 4개 | 3/4 | 3/4 |

16개 비교에는 조건당 51개 기준이 있습니다. 2차 수정 비교의 기준별 결과는 Sonnet 미사용 38 통과·13 실패, 사용 45 통과·6 실패이며, Opus 미사용 40 통과·11 실패, 사용 48 통과·3 실패입니다. 모두 미평가 0개입니다. baseline은 입력·픽스처·모델·도구·판정 기준의 일치를 확인해 재사용했고 각 기록에 출처를 남겼습니다.

첫 실패를 보고 지침을 수정했으므로 이 데이터는 **개발용 회귀 자료**입니다. 독립적인 holdout 평가가 아니며, 단계별로 사례 수와 지침 스냅샷이 다릅니다. 16개 비교 뒤에도 이해도 질문과 안내·예산 템플릿을 수정해 영향받는 사례만 다시 실행했습니다. 최종 파일 전체에서 45개를 모두 재실행했다고 주장하지 않습니다. 지침을 늘린 모든 단계에서 성적이 향상된 것도 아닙니다.

## 개선된 동작과 남은 실패

- **쉬운 이해도 질문:** 원칙만으로는 목적을 빠뜨리거나 세 번호에 여러 질문을 넣었습니다. 질문 템플릿을 추가한 뒤 두 모델 모두 해당 두 기준을 통과했습니다. 각각 한 번의 재검사입니다.
- **안내 경계:** 질문이 이미 정해진 상황에서 Sonnet이 다시 아이디어 구체화로 보냈습니다. 측정이 병목이면 설계로 연결하도록 고친 뒤 두 모델 모두 안내 2개 사례를 통과했습니다.
- **시간 예산:** 단순 합산 지침에서도 범위를 초과하거나 연구자 참석 시간을 제외했습니다. 기간별 상한·배분·합계·축소 규칙 표를 추가한 뒤 두 모델 모두 해당 시간 제한 기준을 통과했습니다.
- **남은 연구 설계 약점:** 마지막 일정 사례에서 Sonnet은 무시할 만한 효과 뒤의 다음 결정을 빠뜨렸고, Opus는 세션·참가자 효과가 균형화된다고 과도하게 표현하고 모집·예약 의존성을 충분히 반영하지 못했습니다. 따라서 마지막 네 사례는 두 모델 모두 3/4입니다.
- **다른 잔여 실패:** 16개 비교에서는 초록·제목만으로 본문 사실을 추정하거나, 점추정치로 원인을 귀속하거나, 표본 수 제안의 가정을 충분히 밝히지 않는 실패가 남았습니다. 계획의 인과 해석·통계·자원 의존성은 연구자가 확인해야 합니다.

실패 판정도 출력과 함께 검토했으며 자동 판정을 지우거나 성공으로 덮어쓰지 않았습니다. 선택적인 추가 제안과 범위 이탈의 경계처럼 판정의 엄격함에 논의 여지가 있는 사례도 있습니다. 정확한 수치와 원문 판단은 기록의 근거를 함께 읽어 주세요.
